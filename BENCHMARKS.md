# Benchmarks: Basalt against Quartz

Generated by `node bench/scoreboard.mjs`; don't edit by hand. Both build the same content, the [savethebees](https://github.com/isaacchacko/savethebees) garden, laid out for Quartz the way its `basalt.json` maps it. Quartz is upstream v4 with its stock config (title, base URL and no analytics changed). Every time is a median.

**Basalt wins 24 of 34 measures.** It loses: cold build; warm build; CSS, median page; video and sound, median page; page, heaviest; everything, heaviest page; requests, median page; start to first page; save to visible in the page.

Measured 2026-10-26 01:57 UTC on Intel(R) Core(TM) i7-8650U CPU @ 1.90GHz (8 threads, 39 GB), Node 25.9.0, Chrome 148.0.7778.167. Basalt `b5c5d29`, Quartz `d25a6ea` (4.5.2), savethebees `a1f80a3`. 3 runs each.
