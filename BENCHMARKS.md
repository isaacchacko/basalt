# Benchmarks: Basalt against Quartz

Generated by `node bench/scoreboard.mjs`; don't edit by hand. Both build the same content, the [savethebees](https://github.com/isaacchacko/savethebees) garden, laid out for Quartz the way its `basalt.json` maps it. Quartz is upstream v4 with its stock config (title, base URL and no analytics changed). Every time is a median.

**Basalt wins 11 of 34 measures.** It loses: cold build; warm build; CSS, median page; video and sound, median page; page, heaviest; everything, heaviest page; requests, median page; `/` performance; `/` accessibility; `/` largest paint; `/` blocking time; `/about` performance; `/about` largest paint; `/about` blocking time; `/blog/ci-cannot-be-that-hard-for-monorepos` performance; `/blog/ci-cannot-be-that-hard-for-monorepos` accessibility; `/blog/ci-cannot-be-that-hard-for-monorepos` largest paint; `/blog/ci-cannot-be-that-hard-for-monorepos` blocking time; start to first page; packages installed; install size; install time.

Measured 2026-10-26 01:09 UTC on Intel(R) Core(TM) i7-8650U CPU @ 1.90GHz (8 threads, 39 GB), Node 25.9.0, Chrome 148.0.7778.167. Basalt `75198a2`, Quartz `d25a6ea` (4.5.2), savethebees `a1f80a3`. 3 runs each.
